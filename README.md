# Bixi Montreal 2024 - Data Analysis

Analysis of 13 million bike trips from Montreal's Bixi bike-sharing network in 2024.

## Key Findings
- Over 12.9 million valid trips after data cleaning
- Metro Mont-Royal is the busiest station with 116,000+ trips
- Peak usage is in the evening (9pm) — unique compared to other cities
- July is the busiest month with 2 million trips
- Usage drops dramatically in winter months (Jan-Feb)
