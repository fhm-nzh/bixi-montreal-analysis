# Bixi Montreal 2024 - Data Analysis

Exploratory data analysis of **12.9 million bike trips** from Montreal's Bixi bike-sharing network in 2024.

## Key Findings
- 13.2 million total trips — 301,180 removed after data cleaning
- **Metro Mont-Royal** is the busiest station with 116,000+ trips
- Peak usage is at **9pm** — unusual compared to other cities where morning commute dominates
- **July** is the busiest month with over 2 million trips
- Usage drops to near zero in January and February (Montreal winter!)
- Most popular routes are short loops — people use Bixi for last-mile metro connections
- Plateau-Mont-Royal borough has the highest average trip duration
